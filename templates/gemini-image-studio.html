About

Gemini Image Studio

Describe a picture and get a real image file in your cabinet.

What you get

A page with a box on it. Write what you want to see, press Send, and about a minute later the picture is sitting in this cabinet as a real file you can drag anywhere. Every picture keeps the words that made it in a small text file beside it, so you can run it again with one thing changed.

There is also a routine that makes a set of four in one go, and it ships switched off. Every picture bills your own Google key, and a routine that spends money on a timer should be switched on by the person paying. Turn it on yourself when you want it.

How to look at it

Open the Studio app in this cabinet. It comes pre-filled with example pictures so the page is not empty — it says on the page that they are examples. Your first real set replaces them.

Before it can make real pictures

Connect Gemini Image in Cabinet's integrations screen. You get an API key from Google AI Studio — sign in, create a key, paste it into Cabinet. Two minutes, once. Cabinet keeps the key in a locked file on your own machine.

What's inside

  • Image Maker — the one agent. Turns your words into a picture.
  • Weekly Image Set — the one routine. Off until you switch it on; Monday at 09:00 once you do.
  • Studio — the one page. Write a description, watch it appear.
